# Changelog

## 1.1.0 - 2026-10-10

- Engine 1.1.0 at **SpinDoctor 3.1.2 parity** (update 3.1.2-298-20261010): 1-298 logical qubits (59 per entangled factor), `mcx7`,
  prepared-factor Born-Z sampling for wide registers, `q.folder` with 3.1.2 semantics, CSV report copies, measurement-CSV fitting.
- New tools: `spindoctor_functions` (in-chat function table) and `spindoctor_test_theory` (theory testing from a file, pasted text, or the
  chat history with user confirmation and quoted excerpts; TXT + JSON + PDF theory test report).
- The repo is the plugin source (v1.0 shipped only a prebuilt `.plugin`), plus `.claude-plugin/marketplace.json` so claude.ai, Cowork
  and Claude Code can add it as a marketplace. `tools/build_plugin.py` rebuilds the `.plugin` reproducibly (tests and tools left out).
- `plugin.json`: GPL-3.0-or-later (was MIT), author RUSSELL PHILIP SMITHSON with email and URL, homepage and repository, descriptions
  updated from 3.0.3 / 29 qubits to 3.1.2 / 298 qubits.
- `.mcp.json`: explicit `"type": "stdio"`, `PYTHONUTF8=1` and `PYTHONDONTWRITEBYTECODE=1`.
- `SKILL.md` rewritten for 3.1.2 and for where it runs (chat uses the CLI through the code tool; Cowork/Claude Code use the MCP tools).
  Commands no longer point at another host's path variable; they use `${CLAUDE_PLUGIN_ROOT}`, which Claude Code fills in.
- Sample theory PDFs are generated by `make_sample_pdfs.py` instead of committed, so the plugin holds text files only (the Claude
  directory holds binary files for manual review).
- Added `tests/claude_host_check.py` (real Claude Code or stand-in), `tests/e2e_mcp.py` and the 3.1.2 reference outputs.
- README, LICENSE (GPL-3.0), NOTICE, COPYRIGHT, SPDX headers.

## 1.0.0 - 2026-10-10

- First Claude `.plugin` (SpinDoctor 3.0.3 semantics, 29-qubit cap).
